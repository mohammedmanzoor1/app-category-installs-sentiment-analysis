          Key observations

          • A large ecosystem.The main KPI cards show approximately 9K total apps.
          • Installs are highly concentrated.Subway Surfers, Google News, Candy Crush Saga, Temple Run 2 and a few others carry very large install totals.
          • Family leads on app count; Game leads on reviews.Family and Tools also show substantial review volume.
          • Free dominates.Free apps are the overwhelming majority of inventory, with a very large gap in review volume versus paid apps.
          • Tone sits next to volume.Sentiment is split into positive, negative and neutral so feedback tone can be read with review counts.

          How it was built

          Scope, objectives, implementation steps and the measures behind the KPIs.

          Project objectives

            Dataset and scope

            AreaDashboard measurePurpose
            App inventoryTotal apps / rated appsMeasure application coverage
            PopularityTotal installsMeasure adoption
            EngagementReviews / ratingsMeasure user interaction
            CategoryApp count / installs / reviewsCompare app segments
            Commercial modelFree vs paidCompare pricing types
            SentimentPositive / negative / neutralSummarize review tone

            The exact source-file row count, cleaning rules, sentiment model and data-refresh date are not visible in the report and should be added if the original documentation is available.

            Implementation steps

            Standardize category, app, pricing, install, rating and review fields. Handle missing values and inconsistent formats.

            Create a clean analytical table, or a star-schema model where appropriate.

            Build KPIs for app count, installs, ratings, reviews and category or type comparisons. See the measures below.

            Use KPI cards, bar charts, donut charts, bubble or scatter visuals, and matrix or table views.

            Use slicers, cross-filtering, drill-through or page navigation where supported.

            Keep titles, units, number formatting and category labels consistent.

              Conclusion
              
  
              The dashboard combines executive KPIs with category, application, pricing, review and sentiment analysis. It shows how raw app-store data becomes an interactive business intelligence product that supports market segmentation, popularity analysis, engagement analysis and review interpretation.
              
  
              For a portfolio or academic submission, the project can be strengthened by documenting the source dataset, cleaning workflow, data model, DAX measures, sentiment methodology and validation checks.
